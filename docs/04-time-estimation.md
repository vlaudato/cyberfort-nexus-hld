# 4. Time Estimation

The following figures are rough-order-of-magnitude engineering estimates, expressed in workdays. They include implementation and automated testing, assume that the requirements and HLD are accepted, and assume that the pre-trained model and 3rd-party Antivirus are available as described by AS-003 and AS-004. Hardware procurement, model training, customer-specific integration, and production operations are excluded.

| Workstream | Estimated workdays |
|------------|-------------------:|
| Capture & Flow Export | 40-60 |
| Network Forensic ingestion and search | 25-40 |
| Command & Control integration | 20-30 |
| File Analysis integration | 20-30 |
| Automatic Cyber Investigator | 35-50 |
| Investigation Portal frontend and backend | 50-70 |
| Deployment, security, and observability | 35-50 |
| Integration, performance, and security testing | 40-60 |
| **Total estimated effort** | **265-390** |

Workstreams can proceed partly in parallel, so the total engineering effort must not be interpreted as the delivery duration. The estimate must be refined after component benchmarks and team allocation are available.
