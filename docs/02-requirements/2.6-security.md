# 2.6 Security Requirements

Security defines how the system protects sensitive data, controls and audits access, and safely handles malicious content across all levels (OS, application, interfaces, and datastores).

- **NFR-014**: The InvP MUST authenticate users through the customer's Identity Provider (IdP) and manage local accounts, in case the customer has no IdP or the customer's IdP is down.
- **NFR-015**: The system MUST enforce role-based access control (RBAC) following the least-privilege model *([FR-INVP-002](2.1-logical-requirements.md#investigation-portal-invp),[FR-INVP-006](2.1-logical-requirements.md#investigation-portal-invp))*
- **NFR-016**: The system MUST encrypt all retained data at rest (NF metadata, alerts, investigations, scan and C&C logs, retained files).
- **NFR-017**: All communication between system components MUST be encrypted and mutually authenticated.
- **NFR-018**: Every SOC analyst action (login, searches, investigation creation and access, edits) MUST be logged to an audit trail that is read only and retained for 1 year.
