# 2.8 Deployment Requirements

Deployment defines the target environment and packaging model of the system: where it runs, how it is installed, and the platform constraints it must respect.

- **NFR-022**: The system MUST be deployable on the customer's premises.
- **NFR-023**: All system components MUST be packaged and delivered as container images. VM-based delivery is acceptable only for components that cannot be containerized.
