# 2.7 Monitoring & Debugging Requirements

Monitoring and debugging define how the system exposes its own health, collects logs and metrics, and provides the information needed to identify and resolve failures.

- **NFR-019**: Every system component MUST report its health status, and the system MUST aggregate these statuses into a single health dashboard covering all components.
- **NFR-020**: Every system component MUST send its logs to a central log collection service, where they can be searched in one place.
