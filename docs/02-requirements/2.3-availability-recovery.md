# 2.3 Availability & Recovery Requirements

Availability refers to the degree to which a system is operational and accessible when needed for use. Recovery defines how quickly the system restores service after a failure (RTO) and how much data loss is acceptable (RPO).

- **NFR-001**: The system MUST maintain 99.9% uptime (approx 8.76 hours downtime per year) or better.
- **NFR-002**: The system MUST recover within ≤ 5 minutes after a failure (RTO). *[AS-007](README.md#assumptions)*
- **NFR-003**: The system MUST not lose more than 5 minutes of data captured prior to a failure (RPO). *[AS-007](README.md#assumptions)*
