
# 3.3 Design Rules & Principles

The following principles guide the design and future evolution of CyberFort Nexus:

- Reduce mirrored traffic to the metadata required by downstream components at the capture edge (ADR-001).
- Keep capture non-blocking: downstream processing must not slow down the live network feed.
- Use asynchronous communication where an immediate response is not required, allowing independent consumption and recovery through replay (ADR-002).
- Keep event and analytical-data write paths append-only.
- Store data according to its shape and access pattern (ADR-003).
- Keep binary content outside the event log and publish only its storage reference.
- Preserve investigation evidence as an immutable snapshot (ADR-005).
- Scale components independently according to their workload and deployment tier.
- Encrypt and mutually authenticate inter-component communication (NFR-017).
